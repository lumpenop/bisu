## 가장 큰 문제 다섯

1. **제안·브리핑 카드가 대화를 덮는다.** 아침 브리핑·제안·목표 카드가 모든 대화의 입력창 위에 고정돼 화면의 35~40%를 차지한다(panel-chat, panel-approval, full-handoff). 승인 카드와 한 화면에 두 개의 주의 카드가 겹쳐 "카드 하나" 원칙이 깨진다.
2. **"지금 무슨 일이 있고, 내가 할 일은 뭔지"를 볼 곳이 없다.** 패널은 최근 대화가 있으면 그 대화로 바로 열려(panel-start가 사실상 대화 화면) 시작 화면이 거의 안 보인다. 다른 대화의 승인 대기·진행 중인 위임·백그라운드 작업은 패널에선 아예 안 보이고, 큰 창에선 목록의 작은 점뿐이다.
3. **상태가 흩어져 있다.** 대화 머리의 얼굴/문구, 목록 아래 제어 상자의 상태 줄, 화면 맨 위 요약 줄, 메뉴바, 기록 막대가 각자 상태를 말한다. 위임이 진행 중인데 머리는 "듣고 있어요"(panel-working).
4. **큰 창 대화 목록 열이 붐빈다.** 봇 카드(사이드바와 중복) → 폴더 입력 + 고르기 → 큰 "새 대화" 버튼 → 목록 → 제어 상자(패널과 중복). 정작 목록은 화면 절반. 다른 봇을 골라도 본문에는 앞 봇의 대화가 남아 목록과 본문이 어긋난다(full-narrow: 목록은 리서치 봇, 본문은 덱 인턴의 승인).
5. **승인 카드가 읽기 어렵다.** 절대 경로가 들어간 명령을 그대로 보여 준다(panel-approval: 6줄짜리 rm). "이 대화에선 계속 허용"이 허용과 같은 무게.

그 밖에
- 대화 머리의 **빨간 「닫기」**가 늘 보인다. 대화를 목록에서 빼는 동작인데 가장 눈에 띄는 버튼.
- 패널 대화 화면엔 지금 **어느 봇**인지, 시작 화면으로 **돌아가는 길**이 없다(＋ 메뉴뿐).
- 사이드바에서 **봇에 딸린 화면(대화·루틴·기억·예약)과 앱 전역 화면(목표·기록·연결·설정)이 한 줄로 섞여** 있어, 기억·루틴이 지금 봇 것이라는 게 화면 제목에만 보인다.
- 비용은 설정 화면 맨 위(2번 클릭)나 메뉴바 오른쪽 클릭에서만. 깨어 있기 상태는 스위치 옆 작은 글씨.
- 확인 창이 두 종류: 우리 스타일 확인 창(권한)과 macOS 기본 confirm(삭제·기록 시작·종료). 문구 톤도 제각각.
- 단축키 없음(새 대화, 빠른 전환, 설정). Esc는 패널 숨기기뿐.
- 중단된 턴은 결과 줄이 '작업 세부 보기'를 켜야만 보여, 멈췄다는 표시가 없다.

## 여정별 현재 클릭 수

| 여정 | 지금 | 막히는 곳 |
|---|---|---|
| a. 아무 데서나 빠르게 묻기 | 단축키 → (최근 대화가 열림) → 새로 하려면 ＋ → 「새 대화」 → 입력: **2클릭** | 지난 대화 맥락으로 열려서 새 질문이 거기 섞인다 |
| b. 하는 일 보고 승인하기 | 그 대화가 열려 있으면 0, 아니면 알림 클릭 또는 큰 창 목록에서 점 찾기: **2~3클릭** | 패널에선 다른 대화의 승인이 안 보인다 |
| c. 맡긴 일·위임 결과 확인 | 원래 대화를 찾아 들어가 넘김 줄 확인: **2~3클릭**. 예약 결과는 입력창 위 카드 | 결과가 대화·카드·목표 화면에 흩어짐 |
| d. 지난 대화 이어 가기 | 큰 창 → 기록 → 찾기 → 이어가기: **3클릭+검색**. 패널은 대화를 닫아야 최근 목록이 보임 | 패널에서 최근 대화로 가는 길이 없다 |
| e. 봇 만들기·고르기·전환 | 만들기 1클릭+대화, 전환 1클릭(큰 창만), 정보 2클릭(모달) | 패널 전환은 시작 화면에서만, 정보는 모달이라 대화와 같이 못 봄 |
| f. 루틴·예약 | 루틴 화면 1 → 실행 1 / 예약 2~3 | 봇을 먼저 골라야 그 봇 루틴이 보인다는 걸 알기 어려움 |
| g. 연결·권한 | 연결 화면 1, 권한은 누를 때 확인 창 | 괜찮음 |
| h. 비용·상태 파악 | 설정 2클릭 / 메뉴바 오른쪽 클릭 | 상태가 한 곳에 없다 |
