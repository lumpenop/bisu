# Dec Intern UX 재설계안 (2026-10-29)

룩은 10-28 그대로(아이보리/차콜, 비취 광택, 블러시, 알약, 스티커, 카드 18px). 바뀌는 건 역할·위계·흐름이다.

## 원칙

1. **패널 = 빠르게 묻고, 지금 하는 일을 보고, 승인하는 곳.** 큰 창 = 봇·대화·루틴·기록을 관리하고 깊게 작업하는 곳.
2. **내가 할 일이 먼저.** 확인 필요(승인)와 진행 중인 일이 어느 화면에서든 가장 먼저 보인다. 제안·브리핑 같은 "읽을거리"는 대화를 덮지 않는다.
3. **상태는 한 곳.** 패널은 머리의 상태 알약 하나, 큰 창은 사이드바 맨 아래 상태 줄 하나. 나머지 상태 문구는 지운다.
4. **봇 → 그 봇의 대화·루틴·기억·예약.** 앱 전역(목표·기록·연결·설정)은 아래로 분리.
5. **앱 제어는 ⋯ 메뉴로.** 설정·종료·스위치는 눈에 덜 띄는 곳에.
6. 한 화면에 주의를 끄는 카드는 하나. 확인 창은 하나의 스타일·문구 톤(“~할까요?” + 결과 한 줄). 단축키 ⌘N ⌘K ⌘, Esc.

## 패널

```
┌──────────────────────────────────────────┐
│ (B) Dec Intern ▾        ● 작업 중 2       ⋯     │  ← 봇 알약(전환) · 상태 알약(하나) · 앱 메뉴
├──────────────────────────────────────────┤
│ 확인이 필요해요                           │  ← 다른 대화의 승인도 여기 (없으면 숨김)
│  ⚠ capture-old.txt 지우기 · 「이 폴더의…」 [보기]
│ 진행 중                                   │
│  ● 리서치 봇에게 넘김 · 반도체 요약  [보기] │
│                                          │
│ 최근                                     │  ← 지금 봇의 최근 대화 3개
│  · 오늘 남은 일정 뭐 있어?        1시간 전 │
│  · 안녕! 오늘 하루 잘 부탁해       어제    │

├──────────────────────────────────────────┤
│ [▶ 메모 정리] [오늘 일정] [선택한 글 요약]  │  ← 추천 행동: 봇 루틴·자주 하는 일·지금 맥락
│ ╭ 덱 인턴에게 말하기 ………………… [보내기] ╮      │
└──────────────────────────────────────────┘
⋯ 메뉴: 새 대화 ⌘N · 전체 창에서 보기 ⌘O · ─ · 선택한 텍스트 읽기 ✓ · 먼저 찾아오기 ✓ · 맥 깨어 있게 ▸ · 보여 주고 가르치기 · ─ · 설정 ⌘, · Dec Intern 종료
```
- 패널을 열면: 지금 대화가 일하는 중이거나 내 확인을 기다리면 그 대화, 아니면 **시작 화면**(지난 대화로 바로 열리지 않음).
- 대화 화면 머리: `← · 제목(봇 · 폴더) · 상태 알약(일할 땐 「멈추기」 포함) · ⋯(새 대화, 전체 창에서 열기, 목록에서 빼기)`. 빨간 「닫기」 버튼은 없앤다.
- 제안·브리핑 카드는 대화 화면에 고정되지 않는다(시작 화면의 한 줄 → 펼침).

## 큰 창

```
┌ 사이드바 ─────────┬ 목록 ───────────────┬ 대화 ─────────────────────────┬ 정보(접힘) ┐
│ Dec Intern        ⌘K   │ 덱 인턴의 대화    [＋]  │ 제목 · ~/Desktop/bisu  ● 작업 중  ⓘ ⋯ │ 봇 정보     │
│ 봇               │ [찾기……………………]     │                               │ 이름·일·폴더 │
│ (B) Dec Intern   ●     │ 덱 인턴이 찾은 것 (1)    │ …대화…                         │ 말투·방식   │
│   대화           │ ⚠ 확인 필요 · 파일 지우기│                               │ [저장]      │
│   루틴           │ 오늘 남은 일정 뭐 있어? │                               │ 봇 지우기   │
│   기억           │ 안녕! 오늘 하루 …      │                               │            │
│   예약           │                      │ ╭ 말하기 ……………………… [보내기] ╮    │            │
│ (리) 리서치 봇    │                      │                               │            │
│ (메) 메모봇       │                      │                               │            │
│ + 봇 만들기       │                      │                               │            │
│ ───────────      │                      │                               │            │
│ 목표 · 기록       │                      │                               │            │
│ 연결 · 설정       │                      │                               │            │
│ ● 듣고 있어요 · 오늘 $0.61 · 깨어 있음 ▾ │                      │                               │            │
└──────────────────┴──────────────────────┴───────────────────────────────┴────────────┘
```
- 사이드바: 고른 봇 아래에만 그 봇의 화면(대화·루틴·기억·예약)이 들여쓰기로 펼쳐진다. 봇 옆 점 = 그 봇에 일하는 대화/확인 필요. 앱 전역은 구분선 아래.
- 사이드바 맨 아래 **상태 줄 하나**: 상태·오늘 비용·깨어 있기. 누르면 작은 창에 스위치 3개와 깨어 있기 방식(지금의 목록 아래 제어 상자를 대신).
- 목록 열: 머리(「덱 인턴의 대화」 + ＋ ⌘N) → 찾기 → 제안 한 줄 → 대화들(확인 필요 대화는 블러시 표시가 맨 위). 봇 카드·폴더 입력·제어 상자는 뺀다.
- 폴더: 새 대화는 봇의 폴더에서 시작. 바꾸려면 빈 대화 머리의 폴더 칩을 눌러 고른다.
- 봇 정보: 모달 대신 **오른쪽 정보 패널**(ⓘ로 접고 펼침, 1180px보다 좁으면 겹쳐 뜸). 봇을 바꾸면 본문은 그 봇의 대화로 함께 바뀐다(어긋남 제거).
- 화면들(루틴·기억·예약·목표·기록·연결·설정)은 지금의 "맨 위 카드 하나 + 그룹 상자" 구조 유지.

## 공통

- **⌘K 빠른 전환**: 봇·대화·화면·명령(새 대화, 봇 만들기, 설정)을 한 칸에서 찾기. ↑↓ Enter, Esc.
- **⌘N** 새 대화, **⌘,** 설정(패널에선 전체 창 설정), **Esc** 창·메뉴·정보 패널 닫기(패널에선 숨기기).
- **확인 창 하나**: macOS 기본 confirm을 우리 확인 창으로 바꾼다. 문구 “~할까요?” + 결과 한 줄, 위험한 쪽 버튼은 블러시.
- **승인 카드**: 경로는 `./`와 `~`로 줄이고 긴 명령은 3줄까지(눌러서 펼침). 버튼은 [허용] [거절], 「이 대화에선 묻지 않기」는 글자 버튼.
- **빈 상태**: 얼굴 + 한 줄 + 할 수 있는 행동 하나. 로딩은 "불러오는 중…" 한 줄, 오류는 블러시 줄 + 다시 시도.

## 여정 클릭 수 (전 → 후)

| 여정 | 전 | 후 |
|---|---|---|
| a. 빠르게 묻기(새 질문) | 단축키 + 2클릭(＋ → 새 대화) | 단축키 + **0클릭**(시작 화면 입력창에 바로) |
| b. 다른 대화의 승인 | 2~3클릭(알림 또는 목록에서 찾기) | **1클릭**(시작 화면/목록 맨 위 「보기」), 상태 알약 「확인 필요」 1클릭 |
| c. 위임·맡긴 일 결과 | 2~3클릭 | **1클릭**(시작 화면 「진행 중」·목록 표시) |
| d. 지난 대화 이어 가기 | 큰 창 3클릭+검색 / 패널은 대화 닫기 필요 | 패널 시작 화면 **1클릭**(최근 3개), ⌘K **1회+입력** |
| e. 봇 전환 | 큰 창 1 / 패널 시작 화면에서만 | 패널 봇 알약 **2클릭**(어디서나), ⌘K, 큰 창 1 |
| e'. 봇 정보 보기·고치기 | 2클릭(모달, 대화 가려짐) | **1클릭**(ⓘ, 대화 옆에 열림) |
| f. 루틴 실행 | 봇 고르기 + 루틴 화면 + 실행 = 3 | 패널 추천 칩 **1클릭** / 큰 창 봇 아래 「루틴」 2 |
| h. 비용·상태 | 설정 2클릭 | **0클릭**(사이드바 상태 줄에 늘 보임) |
