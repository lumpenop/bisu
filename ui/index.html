대화에서 "매일 아침 8시에 어제 커밋 요약해 줘"처럼 말하면 덱 인턴이 예약해 두고, 그 시간에 혼자 해서 결과를 패널 카드로 남겨요. 그때 떠올리기만 하면 되는 일("3시에 알려줘")은 예약 작업이 아니라 미리 알림으로 넣어요.

키

상태
…

덱 인턴은 키를 직접 갖고 있지 않아요. 추가하거나 바꾸려면 Dec Browser → 설정 → 자격 증명에서 사이트 https://openrouter.ai로 OpenRouter 키를 저장하고 「앱 밖에서도 쓰기」를 켠 뒤 덱 인턴을 다시 여세요.

모델 키 순서

같은 일을 할 수 있는 키가 여러 개면 위에서부터 써요. 잔액이 없거나 키가 거부되거나 서버가 응답하지 않으면 다음 키로 같은 요청을 다시 보내고, 실패한 키는 잠시(최대 10분) 맨 뒤로 가요. 이 순서는 Dec과 같이 써요. Claude Code 대화는 새 대화부터 바뀐 순서를 따라요.

고급 · 컴퓨터 조작 시험

컴퓨터 조작 시험

덱 인턴이 텍스트 편집기·Finder·메모·계산기·시스템 설정을 직접 조작해 12가지 일(줄을 추가해 저장, 이름 바꾸기, 메모 만들기, 계산기 열기 같은 것)을 하고, 파일과 답을 보고 채점해요. 시험하는 동안에는 마우스와 창을 덱 인턴이 쓰니 자리를 비울 때 시작하세요. 만든 파일·메모·창은 끝나면 치우고, 휴지통 같은 되돌리기 어려운 동작은 실행하지 않아요.

처음 한 번은 자리에 있을 때 눌러 주세요. 「권한 확인」을 누르면 macOS가 덱 인턴에게 Finder·텍스트 편집기·메모를 다뤄도 되는지 물을 수 있어요 — 허용을 눌러 주세요. 「준비만 해 보기」는 모델 없이 과제를 차렸다 치우기만 해요(창이 잠깐씩 열렸다 닫혀요).
